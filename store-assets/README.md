# 商店宣传图生成方法

## 使用步骤

1. 用 Chrome 浏览器打开下面的 HTML 文件
2. 按 F12 打开开发者工具
3. 按 Ctrl+Shift+M 进入设备模拟模式
4. 在顶部尺寸栏输入对应尺寸（如 1280x800）
5. 按 Ctrl+Shift+P，输入 "screenshot"，选择 "Capture full size screenshot"
6. 保存得到的 PNG 图片，直接上传到商店

## 文件说明

| 文件 | 尺寸 | 用途 |
|------|------|------|
| `screenshot-1280x800.html` | 1280x800 | Chrome/Edge 商店截图 |
| `screenshot-640x400.html` | 640x400 | Chrome/Edge 商店截图（小） |
| `promo-1400x560.html` | 1400x560 | Chrome 商店大宣传图 |
